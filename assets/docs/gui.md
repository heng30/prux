# 桌面界面（GUI）

除终端界面外，prux 还提供一个桌面窗口版本，可执行文件为 `prux-gui`。它和终端界面共用同一套内核：
同一个 `agent_dir()`（默认 `~/.prux`）、同一份 `settings.json`、同一批会话文件，同一个会话可以在
两边轮流打开，上下文与工具完全一致。区别只在呈现方式与键位：桌面版有鼠标、并排的面板与独立的
外观设置，键位是固定的（不读 `keybindings.json`）。

## 启动

```bash
prux-gui            # 当前目录开新会话
prux-gui -c         # 接着最近一个会话
```

启动参数与终端界面相同（会话选择、初始消息、模型覆盖、`--theme`、项目信任的 `-a` / `--no-approve`
等，见[快速开始](quickstart.md)）。`--theme` 只在还没存过桌面主题时生效，存过之后以 `settings.json`
的 `theme-gui` 为准。

- 窗口默认 1180×780，最小 760×560；界面字体内置（思源黑体 CN），不需要系统装中文字体。
- 项目里有需要信任的资源、又没存过决定时，启动会先弹出信任面板（`/trust` 可以重新打开）。

## 屏幕布局

```
┌──────────┬──────────────────────────────────────────────┬──────────┐
│ 侧栏      │  消息区（历史 + 流式输出，占满剩余高度）        │ 右侧面板  │
│ 会话列表  │                                              │ Files /  │
│          │  待发送区（有排队消息时才出现）                 │ Changes  │
│          │  停靠面板（有扩展状态时才出现）                 │ （可收起）│
│          │  输入卡片（多行编辑 + 提示行 + Send）           │          │
│ 工作目录  │  状态行（1 行：忙碌 / 上下文 / token / 费用）    │          │
└──────────┴──────────────────────────────────────────────┴──────────┘
```

- **侧栏**：会话列表，可收起（`Ctrl-Shift-B`），右边界可拖动改宽。
- **消息区**：占满剩余高度，右侧有滚动条（鼠标悬停时显示）。
- **待发送区**：有排队中的消息时占行，否则不占布局。
- **停靠面板**：扩展报告运行中工作时出现（子代理、任务流、下载、远程会话……），`/dock` 切换。
- **输入卡片**：多行编辑器 + 附件/模型/thinking 控件 + `Send` 按钮。
- **状态行**：固定 1 行，见[状态行](#状态行)。
- **右侧面板**：文件与变更两页，默认收起，`Ctrl-Shift-E` 开关。

所有区域的尺寸都跟随界面缩放（见[外观与缩放](#外观与缩放)）。

## 侧栏

顶部是 `prux` 标题与 `+ New session`，中间是会话列表，底部是当前分支与工作目录。

- 会话按最近活动时间分组：`Today` / `This week` / `Older`；每行显示标题（会话名或首条用户消息）、
  相对时间与消息数。
- 单击一行切换到该会话；右键打开 `Rename` / `Delete` 菜单（删除会再确认一次）。
- 元数据在后台逐条读入：列表先出行，再补齐标题与消息数；一条都还没就绪时显示 `Loading sessions…`。
- 底部的工作目录一行点击后打开选择面板：最近用过的目录 + `Browse…`（系统目录选择器）。
- 会话多到超出高度时在列表内部滚动；关闭侧栏后主区占满窗口。

## 消息区

按时间线渲染会话历史，块类型与终端界面一致：

| 块 | 呈现 |
| 用户消息 | 带背景的气泡，右对齐，Markdown 正文；过长时折叠，点击气泡展开 |
| 助手回复 | Markdown 正文（标题、列表、引用、分隔线、行内代码/强调/链接） |
| 思考块 | 可折叠的灰字，`Ctrl-T` 显示/隐藏 |
| 工具调用 | 卡片：头部是工具名与路径，`edit` 显示 diff（行号列 + 增删配色，单行替换按词高亮），`write` 折叠预览要写入的正文；下方是工具输出与状态（进行中 / 成功 / 失败） |
| 图片 | `@图片` 引用与工具返回的图片渲染成缩略图（最大边长 360，随界面缩放） |
| 系统消息与提示 | 灰底细边框，或对话流里的一条提示行（压缩、重试、中断、`$ 命令` 输出等） |

**折叠与展开**：`Ctrl-O` 切换「全部展开」，点击任一工具卡片只切换该块；展开状态只影响显示。

**文本选择**：左键拖选对话流里的文字（按真实折行与字符宽度定位），`Ctrl-C` 或 `Ctrl-Shift-C` 复制；
对话流里没有选区时 `Ctrl-C` 清空输入框。`Ctrl-X` 复制最后一条助手回复。

**滚动**：

- 滚轮滚动消息区，指针在消息区内才生效；滚动条在鼠标悬停消息区时出现，可以拖动。
- 快速连滚会按手感加速（孤立一格按系统自己的步长，最快约 10 倍），按住 `Alt` 再乘 5，用来快速跳过长回复。
  触控板的小增量按原样累加，不会变成整格跳动。
- `Ctrl-Home` 到顶、`Ctrl-End` 到底、`Shift-PgUp` / `Shift-PgDn` 按视口翻页。
- 新输出到来时自动跟随到底；手动往上滚之后停止跟随，滚回底部或按 `Ctrl-End` 恢复跟随。

**空会话**：还没有任何内容时，主区居中显示 `What should we build today?`、一句快捷键提示与输入卡片。

## 输入卡片

多行编辑器，按真实字宽折行，超过 8 行时在卡片内部滚动，光标移动会自己滚进视口；中文/日文输入法
的组字候选窗贴着输入框弹出。

- `Enter` 提交，`Shift-Enter` 或 `Ctrl-J` 换行，`Tab` 插入两个空格。
- 忙碌时提交不会开新回合：`Enter` 把消息排进 steer 队列（回合内注入），`Alt-Enter` 排进 follow-up
  队列（本轮结算后再发）。排队中的消息显示在输入卡片上方的待发送区，`Alt-Up` 可以把它们一次全部
  取回编辑器。
- 首行以 `!` 开头时直接在本机执行 shell 命令，输出作为用户消息进入上下文；`!!` 同样执行，但输出
  只在对话流里显示、不进入模型上下文。
- **补全**：行首输入 `/` 弹出命令候选（内置命令 + `/skill:名称` + 已启用扩展声明的命令），输入 `@`
  弹出文件候选；带子命令的扩展命令在命令名后敲空格会弹出二级候选。
  - `Tab` 只补全；`Enter` 补全后立即执行（`@` 文件只补全，不提交）。
  - `/` 面板里敲空格会先补全命令名，然后把后续输入交给子命令候选。
  - `↑` / `↓`（或 `Ctrl-K` / `Ctrl-J`）移动，`PgUp` / `PgDn` 翻页，`Esc` 收起本次补全，继续删到触发符
    才重新弹出。
- **附件**：`+ Attach` 菜单里的 `File` / `Image` 就是插入一个 `@` 引用，并让补全面板只列（或优先列）
  对应类型；图片引用在对话流里渲染成缩略图。`Ctrl-V` 粘贴文本。
- **控件**：模型 chip 打开模型选择，thinking chip 打开思考级别选择；`Send` 按钮在忙碌时变成停止按钮。
- 输入框内容为空时 `Ctrl-D` 退出，`Ctrl-Q` 任何时候都能退出。

## 待发送区与状态行

- **待发送区**：忙碌时排队的 steer / follow-up 消息逐条列出，末尾提示 `Alt-Up to edit all queued messages`。
- **状态行**（在输入卡片下方，固定 1 行）：
  - 左：忙碌指示（闪烁圆点 + 当前动作）、消息数、上下文占用量、缓存命中率。
  - 右：本轮 in/out token、费用、输出速率、计划与目标标记、交互数、耗时。

## 右侧面板

两个页签，点击页签或按快捷键切换，`Esc` 收起，左边界可拖动改宽：

- **Files**（`Ctrl-Shift-F`，切到该页会自动聚焦搜索框）：按路径过滤的工程文件列表，点一行在下方显示
  文件正文（语法高亮、长行不折行，横竖滚动条都可拖）。搜索框聚焦时按键归它，`Esc` / `Enter` 退出聚焦。
- **Changes**（`/giff` 打开）：`git status` 里的未提交变更，行首是状态字母（`M` / `A` / `D` / `R` / `??`），
  点一行看该文件的 diff；换文件或换变更时滚动位置回到顶部。

## 停靠面板

会报告运行中工作的扩展（子代理、任务流、下载、远程会话等）把状态写在这一块里，位置在输入卡片上方。
扩展启动时请求打开就会显示，`/dock` 切换开关；内容超过几行时在面板内部滚动，没有扩展有话要说时整块
不占布局。计划模式的待办（`/todos`）也显示在这里。

## 覆盖层与对话框

覆盖层分三类：居中的列表面板（命令面板、会话/模型/思考/主题选择、设置、扩展、技能）、贴着输入卡片
上方弹出的信息卡片与扩展面板、以及带输入框的对话框。打开覆盖层时按键只喂它，`Esc` 逐层退出。

**列表面板通用键位**：

| 键 | 动作 |
| `↑` / `↓`，`Ctrl-K` / `Ctrl-J` | 上下移动选中项 |
| `Home` / `End` | 第一项 / 最后一项 |
| `PgUp` / `PgDn` | 翻页（12 行） |
| 直接打字 | 过滤（大小写不敏感的子串匹配） |
| `Enter` | 执行选中项；有详情页的面板先打开详情 |
| `Space` | 设置 / 扩展 / 技能面板里改这一行的取值 |
| `Esc` / `Ctrl-C` | 关闭；详情页先退回列表 |

**各面板要点**：

- **命令面板**（`Ctrl-M`）：只列 `/` 面板里没有的东西，外加有独立面板的 `Skills` / `Settings` /
  `Extensions…`、切换外观、右侧面板等视图动作。
- **会话选择器**（`Ctrl-Shift-O`）：切会话；`Ctrl-R` 重命名、`Ctrl-D` 删除、`Ctrl-G` 跳到当前会话的
  下一个会话。
- **模型 / 思考 / 外观**：`Ctrl-L`、`Shift-Tab`（循环级别）、`Ctrl-Shift-G`；`Ctrl-P` / `Ctrl-Shift-P`
  直接切上一个/下一个模型（只在「模型循环名单」里挑）。
- **设置面板**（`Ctrl-,`）：与终端界面同一份 `settings.json` 的开关与数值，`Space` 改值，数字项弹输入框
  （`Enter` 写盘，留空表示清除）。条目含义见[设置](settings.md)。
- **扩展 / 技能面板**（`/extension`、`Ctrl-I`）：勾选只改未落盘的草稿，
  `Ctrl-S` 才写盘并重建工具，`Esc` 丢弃；`Enter` 打开当前条目的详情页（描述、模式、工具、来源）。
- **信息卡片**：`/session`（当前会话概要）、`/hotkeys`（键位摘要）、`Ctrl-Shift-U`（用量与费用）。
  卡片主体有高度上限，`↑` / `↓` / `PgUp` / `PgDn` / `Home` / `End` 滚动，右侧显示滚动条。
- **信任面板**（启动或 `/trust`）：`Trust`、`Trust parent folder (…)`、`Trust (this session only)`、
  `Do not trust`、`Do not trust (this session only)`，以及 `Remove all saved trust decisions`。
  落盘的选项写进 `trust.json` 下次生效，两个「仅本次」选项立即重载技能、上下文文件与工具。
- **扩展覆盖层**：扩展发起的问卷、配额、审阅等面板贴在输入卡片上方。带输入行时按 `i` 聚焦、`Enter`
  提交、`Esc` 交回焦点；`Esc` 再按一次或 `Ctrl-C` 关闭整个面板。
- **对话框**：会话重命名、删除确认、API key、数值设置、导入路径、分支标签、`/bug` 的复现描述。
  `Enter` 确认、`Esc` 或 `Ctrl-C` 取消。
- **toast**：右上角短暂提示（最多 4 条，约 3.6 秒消失），用于「已复制」「已保存」这类一次性反馈。

键位固定在程序里，不读 `keybindings.json`（那份配置只作用于终端界面）。`/hotkeys` 会打开一份

**编辑输入框**：

| 键 | 动作 |
| `Enter` | 提交（忙碌时排进 steer 队列） |
| `Shift-Enter` / `Ctrl-J` | 换行 |
| `Alt-Enter` | 排 follow-up（本轮结算后发送） |
| `Tab` | 插入两个空格 |

**面板与视图**：

**消息区**：

## 斜杠命令

在桌面版里输入 `/` 后按 `Tab` 或 `Enter`。面板列出的是能在这里执行的那部分，另有 `/skill:名称` 与
已启用扩展声明的命令。未知命令不会报错，原样留在输入框里。

| 命令 | 说明 |
| `new` | 新建会话 |
| `resume` / `sessions` | 打开会话选择器 |
| `model [id]` | 打开模型选择，或直接切到该模型（在模型循环名单里匹配） |
| `thinking [level]` | 打开思考级别选择，或直接设定级别 |
| `compact` | 压缩上下文 |
| `copy` | 复制最后一条助手回复 |
| `rewind` | 撤销上一条用户输入（回到发送前的状态） |
| `session [n]` | 显示当前会话概要；带序号时切到该会话 |
| `name [text]` | 重命名当前会话 |
| `label` | 给当前分支打标签 |
| `fork` / `clone` | 派生 / 复制当前会话 |
| `tree` | 输出会话树 |
| `import [path]` / `export [path]` | 导入 / 导出会话 |
| `share` | 分享会话（导出 + gist） |
| `history` | 搜索输入历史，选中后写回输入框 |
| `giff` | 打开右侧面板的 Changes 页 |
| `trust` | 项目信任面板 |
| `reload` | 重载技能、扩展与上下文文件 |
| `theme` / `appearance` | 外观面板 |
| `settings` | 设置面板；`/settings <扩展名>` 只显示该扩展的设置 |
| `extension` / `skills` | 扩展 / 技能面板 |
| `scoped-models` | 编辑 `Ctrl-P` 循环用的模型名单 |
| `login` / `logout` | 保存 / 删除某个 provider 的 API key |
| `changelog` | 当前版本的更新日志（Markdown 渲染，可滚动） |
| `hotkeys` | 键位摘要 |
| `bug` | 收集诊断信息并打包成 zip |
| `debug` | 输出诊断信息（provider / model / 消息数 / 自动压缩与重试 / 工作目录 / 会话）；`/debug info`、`/debug provider`、`/debug system-prompt` 由 `debug` 扩展提供（需在 Dev 模式下启用） |
| `usage` | 打开 `usage` 扩展的配额面板（该扩展启用时） |
| `dock` / `sidebar` | 停靠面板 / 侧栏显隐 |
| `quit` | 退出 |

只提供终端界面的扩展命令在这里会提示「Extension command … is terminal-only; use the terminal UI」，
不会静默失败。

## 外观与缩放

- 桌面版只有明暗两套主题（中性石墨配色 + 珊瑚强调色），与终端界面的多主题体系相互独立：
  桌面主题存 `settings.json` 的 `theme-gui`，终端主题存 `theme`，互不覆盖。
- 界面缩放存 `settings.json` 的 `uiScale`（默认 `1.5`，范围 0.8–5.0，步进 0.1）。`Ctrl-=` / `Ctrl--`
  逐档调整，`Ctrl-0` 回到 100%；外观面板里也能选。
- 其余设置（自动压缩、重试、thinking 显示、语法高亮、图片处理、steering / follow-up 模式等）与终端
  界面共用同一份 `settings.json`，改哪边都生效，含义见[设置](settings.md)。

## 与终端界面的差异

- **键位固定**：桌面版不读 `keybindings.json`，键位表见上文；终端界面的键位见[键位绑定](keybindings.md)。
- **底栏**：终端界面的底栏（footer 扩展）只在终端渲染；桌面版的等价信息分散在输入卡片的 chip 与
  状态行里。停靠面板（dock）两边都有。
- **滚轮速度**：桌面版按系统步长加速。终端界面的 `fullscreenWheelScrollLines`（`/settings` 里的
  Wheel scroll lines）只作用于终端界面。
- **鼠标**：桌面版支持拖选、拖动滚动条、拖动侧栏/面板边界、右键菜单、点卡片展开、点 chip 开面板。
- **主题**：桌面版两套，终端界面多套自定义主题（见[主题](themes.md)）。
- **扩展**：扩展注册的工具、命令、快捷键、覆盖层与停靠段两边共用；扩展请求的列表选择与输入行在
  桌面版里同样会弹出对应面板。

## 故障排查

- **没有 `prux-gui` 可执行文件**：这个二进制只在启用桌面界面构建时才产出，用 `prux` 即可。
- **界面太小 / 太大**：`Ctrl-=` / `Ctrl--`，或直接改 `settings.json` 的 `uiScale`；缩放过大时侧栏与输入
  卡片会被挤，`Ctrl-0` 快速回到 100%。
- **窗口里看不到自己的会话**：两侧共用 `agent_dir()` 下的会话目录，先确认两边用的是同一个
  `agent_dir()`（见[环境变量](environment-variables.md)）。
- **启动就弹信任面板**：项目里有需要信任的资源且没存过决定，选择会写进 `trust.json`，下次不再询问。
